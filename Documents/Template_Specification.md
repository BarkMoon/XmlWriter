# テンプレート仕様書

本ツールで使用可能なテンプレートファイルの記述仕様について解説します。

## 0. テンプレートの2つの用途

テンプレートは実行モードによって処理系が異なり、**使えるマクロが変わります**。混在はできません。

| 用途 | モード | 主に使うマクロ | 1レコードの単位 |
| :--- | :--- | :--- | :--- |
| **C#クラス生成** | `Code` / `All` | `#ForAllSubClasses`, `#ForAllSubClassProperties`, `@RootProperties`, `@SubClass*` | テーブル（＝1クラス） |
| **データスクリプト生成** | `DataCode` | `#ForAllData`, `${列ヘッダ名}` | データ行（＝ループ1回） |

`#If` / 関数マクロ / `#EraseDuplicatedLine` / `@TableName` / `@GeneratedDate` は **どちらの用途でも共通**で使えます。

> クラス生成テンプレートの実例は `Templates/Template_Card.cs`・`Template_CardCollection.cs`、データスクリプト生成の実例は `Templates/Test_DataScript.cs` を参照してください。

---

## 1. 変数置換

### グローバル変数（全用途共通）
*   **`@TableName`**: 対象のテーブル名（シート内テーブル名）。クラス生成ではそのままルートクラス名になります。
*   **`@GeneratedDate`**: 生成日時（`yyyy/MM/dd HH:mm:ss`）。

### クラス生成用の変数
*   **`@RootProperties`**: ルートクラス直下のプロパティ定義（`[XmlElement(...)]` 付きのC#プロパティ群）が自動生成されて展開されます。ドットを含まないヘッダ、およびサブクラスへの参照プロパティが対象です。
*   **`@SubClassName`**: 現在処理中のサブクラスのC#クラス名（親を連結した一意名。例: `CardData_Status`）。`#ForAllSubClasses` ブロック内で有効。
*   **`@SubClassTagName`**: そのサブクラスの元のXMLタグ名（例: `Status`）。`#ForAllSubClasses` ブロック内で有効。
*   **`@SubClassPropertyName`**: 現在処理中のプロパティ名。`#ForAllSubClassProperties` ブロック内で有効。
*   **`@SubClassPropertyType`**: そのプロパティのC#型（プリミティブは変換、配列は `List<T>`、子クラス参照はそのクラス名）。`#ForAllSubClassProperties` ブロック内で有効。

### データスクリプト生成用の変数
*   **`${列ヘッダ名}`**: `#ForAllData` ループの各反復で、その行の対応セル値に置換されます。
    *   ドット区切りヘッダはパスを連結したキーで指定します。例: `${Id}`, `${Name.OriginalName}`, `${Properties.Suit}`
    *   **この記法はデータスクリプト生成（`DataCode`）専用です。** クラス生成テンプレートでは機能しません。

## 2. 制御マクロ

### 2-1. 全行ループ（データスクリプト生成用）
**`#ForAllData` ～ `#EndForAllData`**

Excelの有効なデータ行の数だけ、ブロック内の記述を繰り返します。各反復で `${...}` の置換と、ブロック内の `#If`・関数マクロの評価が行われます。

### 2-2. サブクラスループ（クラス生成用）
**`#ForAllSubClasses` ～ `#EndForAllSubClasses`**

ドット区切りヘッダ（例: `Status.Month`, `Properties.Flower`）から構築される**ネストしたサブクラス（ルート以外の全ノード）**の数だけ、ブロック内を繰り返します。

*   各反復で `@SubClassName` / `@SubClassTagName` が置換されます。
*   ブロック内に `#ForAllSubClassProperties` を入れ子にでき、さらにブロック内の `#If`・関数マクロも評価されます。
*   ルートクラス自身は対象外です（ルート直下のプロパティは `@RootProperties` が担当）。

### 2-3. サブクラスプロパティループ（クラス生成用）
**`#ForAllSubClassProperties` ～ `#EndForAllSubClassProperties`**

`#ForAllSubClasses` の内側で使用し、**現在のサブクラスが持つプロパティ**の数だけ繰り返します。対象は次の両方です。

*   そのサブクラス直下のスカラ／配列プロパティ
*   そのサブクラスがさらに持つ子クラスへの参照（この場合 `@SubClassPropertyName` は子のタグ名、`@SubClassPropertyType` は子のクラス名）

各反復で `@SubClassPropertyName` / `@SubClassPropertyType` が置換されます。

### 2-4. 条件分岐（全用途共通）
**`#If(条件式)` ～ `#Elif(条件式)` ～ `#Else` ～ `#Endif`**

条件式が `True` に評価されたブロックのみ出力します。いずれも真でなく `#Else` があればそれを出力します。

*   **ネスト可能**です（対応する `#Endif` を深さで解決します）。
*   行頭のインデント付きで記述した `#If` は、適合時にインデントを保ったまま展開され、不要な空白行は除去されます。
*   条件式には下記の関数マクロを使用します。最終的に文字列 `True` に簡約された場合のみ真と判定されます。

### 2-5. 重複行削除（全用途共通）
**`#EraseDuplicatedLine` ～ `#EndErase`**

ブロック内の行のうち、**内容が重複する行**を削除します。

*   判定は各行を **`Trim()` した文字列**で行い、**最初に出現した行だけ**を残します。
*   **空行も同様に扱われ**、連続・重複する空行は最初の1つに圧縮されます（インデント違いの空行も同一視）。
*   `using` 句の整理や、ループ展開で生じた重複定義の排除に利用します。

## 3. 関数マクロ（条件式・文字列処理）

`#If` の条件式のほか、テンプレート本文でも使用できます。ネスト可能で、内側から順に評価されます（変化が無くなるまで繰り返し簡約）。

*   **`#Eq(A, B)`**: A と B が等しければ `True`
*   **`#Not(A)`**: A が `True` なら `False`（否定）
*   **`#And(A, B, ...)`**: すべて `True` なら `True`
*   **`#Contains(A, B)`**: A が B を含めば `True`（部分文字列判定）
*   **`#Or(A, B, ...)`**: いずれかが `True` なら `True`
*   **`#Replace(Text, Old, New)`**: `Text` 内の `Old` を `New` に置換して返す（条件式以外でも使用可）

> **注意:** 引数はカンマ `,` で区切られ、括弧 `(` `)` を引数内に含められません（正規表現で最内の `#name(...)` を評価するため）。`@TableName` 等のグローバル変数を引数に使う場合、クラス生成では `@RootProperties`・`@SubClass*` 展開後・最終条件分岐の段階で `@TableName` が先に置換されてから評価される点に注意してください（下記「処理の実行順序」参照）。

## 4. エクセルヘッダ拡張

Excelの1行目（ヘッダ行）で使える特殊記法です。

### `#` で始まる列の無視
ヘッダ名の先頭に `#` を付けると、その列はコメント扱いとなり、XML・コード生成・スクリプト生成のすべてで無視されます。
*   例: `#Memo`, `#UnusedParam`

### 型指定
`プロパティ名:型` の形式で型を指定します（省略時は `string`）。末尾に `[]` を付けると配列（C#では `List<T>`、XMLでは同名タグの繰り返し）になります。
*   例: `Status.Month:int`, `Tags:string[]`

### テーブル参照と埋め込み
`プロパティ名:参照テーブル名(参照キー列名)[]` の形式で、別テーブルのデータを検索してリスト埋め込みします。

*   **動作**:
    1.  対象セルの値（カンマ区切り）をキーとして読み取る
    2.  `参照テーブル名` の `参照キー列名` 列を検索する
    3.  一致した行のデータを `プロパティ名` 配下にXMLとして展開する（C#クラス生成では `List<参照テーブル名>` 型）
*   例: `Abilities:AbilityTable(Name)[]`
    *   セル値が `Fire, Ice` の場合、`AbilityTable` から `Name` が `Fire`・`Ice` の行を探し、`Abilities` タグ配下に展開します。

## 5. 処理の実行順序

用途ごとにパイプラインが異なります。

### C#クラス生成（`Code` / `All`）
1.  **クラスツリー構築**: ヘッダのドット区切りからルート＋サブクラスの木を作る。
2.  **サブクラス展開**: `#ForAllSubClasses` / `#ForAllSubClassProperties` を展開し、`@SubClass*` を置換。各ブロック内で条件分岐・関数マクロも評価。
3.  **ルートプロパティ生成**: `@RootProperties` を自動生成コードに置換。
4.  **グローバル変数置換**: `@TableName`, `@GeneratedDate`, `@RootProperties` を置換。
5.  **最終条件分岐**: ループ外の `#If`・関数マクロを評価。
6.  **重複行削除**: `#EraseDuplicatedLine` を適用。
7.  **改行コード正規化**: すべて CRLF に統一。

### データスクリプト生成（`DataCode`）
1.  **全行ループ展開**: `#ForAllData` を行数分展開し、各行で `${...}` 置換と条件分岐・関数マクロを評価。
2.  **グローバル変数置換**: `@TableName`, `@GeneratedDate` を置換。
3.  **最終条件分岐**: ループ外の `#If`・関数マクロを評価。
4.  **重複行削除**: `#EraseDuplicatedLine` を適用。
5.  **改行コード正規化**: すべて CRLF に統一。
